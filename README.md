# E-Check Payment Form

This repository hosts the E-Check payment form for Designer Closets & Cabinets.

## Features
- Pre-populated form fields from URL parameters
- Professional design matching company branding
- Mobile-responsive layout
- Secure payment processing

## URL
The form is available at: https://YOUR_USERNAME.github.io/echeck-forms/

## Setup Instructions
1. Upload the contents of this folder to your GitHub repository
2. Enable GitHub Pages in repository settings
3. Set source to "Deploy from a branch" and select "main" branch
4. The form will be available at the URL above

## Usage
The form accepts URL parameters for pre-population:
- customerName
- customerEmail  
- customerPhone
- jobNumber
- amount
- paymentType
- description

Example: https://YOUR_USERNAME.github.io/echeck-forms/?customerName=John%20Doe&amount=1500.00

## Form Features
- **Professional Design**: Matches Designer Closets branding
- **Mobile Responsive**: Works on all devices
- **Pre-population**: Automatically fills fields from URL parameters
- **Validation**: Client-side form validation
- **Security**: Secure payment processing integration

## Technical Details
- Built with HTML5, CSS3, and JavaScript
- No external dependencies required
- Compatible with all modern browsers
