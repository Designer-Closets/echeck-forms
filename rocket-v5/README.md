# Rocket V5

Working folder for the next iteration of the E-Check payment form.

This folder is seeded with a copy of the root `index.html` as a starting point.
Build and iterate here, then promote changes to the root when ready.

## Local preview
Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
# then visit http://localhost:8000/rocket-v5/
```
